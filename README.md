# FizzBuzz (1〜50) Web アプリケーション

1から50までの数値を判定し、結果を色分けされたグリッドカードでアニメーション表示するシンプルな Web アプリケーションです。

## 主な特徴

- **視覚的な色分けデザイン**:
  - **通常の数値**: シンプルなニュートラルカード
  - **Fizz（3の倍数）**: ブルー系バッジ
  - **Buzz（5の倍数）**: グリーン系バッジ
  - **FizzBuzz（15の倍数）**: グラデーション＆星マーク付き特別ハイライト
- **アニメーション描画**:
  - 「FizzBuzz を実行」ボタンをクリックすると、1〜50 のカードが順番にテンポよくポップアップ表示されます。
- **インタラクション制御**:
  - 実行中の二重押し防止
  - リアルタイムな進捗状況表示（例: `生成中... (25/50)`）
  - 中断・リセット機能
- **レスポンシブ対応**:
  - スマートフォンやタブレットなどの画面サイズにも柔軟に対応する CSS Grid レイアウト。

## FizzBuzz の判定ルール

| 条件 | 表示内容 | スタイル |
| :--- | :--- | :--- |
| 15 の倍数（3かつ5の倍数） | `FizzBuzz` | グラデーション / アクセント |
| 3 の倍数 | `Fizz` | ブルー |
| 5 の倍数 | `Buzz` | エメラルドグリーン |
| 上記以外 | 数字そのまま | ライトグレー |

## 利用方法

サーバーのセットアップや特別なツールのインストールは不要です。

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` をお好みのブラウザ（Google Chrome、Edge、Firefox、Safari など）で直接ダブルクリックして開きます。
3. **「FizzBuzz を実行」** ボタンを押して動作をご確認ください。
